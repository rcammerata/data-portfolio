Data analysis portfolio

Two end-to-end projects: data pipelines into SQL Server, a star schema, and Power BI reports on top. Everything runs on a small home server and refreshes itself.

Home climate analytics

Sensor readings and a dehumidifier's activity, collected every 5 minutes and modelled in SQL Server. Did the automation keep the room dry, and what did it cost?

Collecting data; the first summaries appear after a few days.

SQL Server · T-SQL (window functions, gaps and islands, JSON) · Python ETL · Power BI · DAX

Retail sales analytics

Millions of real liquor sales lines published by the State of Iowa, loaded month by month into a columnstore star schema: trends, category mix, vendors and stores.

Loading the state's sales data; summaries appear once the first months are in.

SQL Server · columnstore · incremental loads · data quality checks · Power BI · time intelligence

How it works

Loaders written in Python pull new data on a schedule (Home Assistant every 15 minutes, the state's open-data API monthly) and hand it to stored procedures that clean it and load a star schema in SQL Server 2025. Power BI reads reporting views through a read-only login. Once a day the server exports these small public summaries to this page; nothing here can reach back into the home network.
